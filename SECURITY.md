# Security

If you find a security problem in Fletchr (the app or the server), please tell us privately before you publish it:

- use GitHub's **Report a vulnerability** on the Security tab of this repository (private vulnerability reporting), or
- write to **kontakt@fletchr.de**.

Please include what you found, how to reproduce it, and which version (Settings, About in the app, or `/api/health/` on the server). We will answer as soon as we can and tell you when it is fixed. Please do not test against other people's installations or access data that is not yours.

Only the latest release is supported. The project is run by one person, so a fix may take some days.

Passwords, keys and `.env` files do not belong in issues or commits. If you ever see one in this repository, report it the same way.
