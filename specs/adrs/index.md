# ADRs

Short decision records for choices that had genuine considered-and-rejected alternatives
(MADR-lite: Context, Considered Options, Decision Outcome, Consequences). Files are named
`NNNN-topic.md`.

- [0001-django-drf-sqlite-backend.md](0001-django-drf-sqlite-backend.md): Django + DRF + SQLite instead of PocketBase, Supabase or Node. *accepted*
- [0002-vue-capacitor-instead-of-expo.md](0002-vue-capacitor-instead-of-expo.md): Vue 3 + Capacitor instead of Expo. *accepted*
- [0003-phone-converts-videos-before-upload.md](0003-phone-converts-videos-before-upload.md): the phone converts videos, the server does not. *accepted*
- [0004-merging-sessions.md](0004-merging-sessions.md): the server merges a coach's empty session with the archer's, by a rule on pairs. *accepted*
- [0005-sign-in-methods-are-separate.md](0005-sign-in-methods-are-separate.md): Google and email accounts are separate, no linking, no email matching. *accepted*
- [0008-events-are-labels.md](0008-events-are-labels.md): a team training is a label on sessions, notes and media, not a shared session. *accepted*
